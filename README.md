# Examples

This repository is an open collection of examples of solving groundwater problems with Timflow and QGIS-Tim.

Keep in mind that Timflow is evolving over time, whereas the examples showcase the use at the time of publishing.


## Analysis of pumping tests with the transient predecessor of Timflow
[External link: Historic pumping tests are analysed with TTim.](https://github.com/Died1808?tab=repositories), locations A15, A27 (Tussen de Rails), Amstelveen, Berlicum, De Lier, ELst, Moerkapelle. In Dutch. Contributed by Dick Edelman (2023).

## Can a large scale dewatering project replace a pumping test?
[Historical analysis of large scale dewatering of Vlaketunnel in Zeeland in spring 2011.](https://github.com/tim-groundwater/Examples/blob/main/analysis-historic-dewatering-vlaketunnel/analysis.ipynb) QGIS-Tim for model setup, analysis with Timflow (steady) in ModelMaq. In English. Contributed by Hendrik Meuwese (2023).

## The equivalent permeability of an aquifer below a levee.
[Analysis of impact of permeability differences in an aquifer below a levee.](https://github.com/tim-groundwater/Examples/tree/main/equivalent-permeability-aquifer-levee) Use of Timflow in an xsection (1D) model. In Dutch. Contributed by Hendrik Meuwese (2023).
